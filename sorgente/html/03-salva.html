Sincronizza telefono e computer

GitHub privato (consigliato)

Gratis. Archivio, listino, dati ditta e stile restano uguali su telefono e computer. I dati stanno in un archivio privato del tuo account GitHub.

Prima volta? Guida passo passo (circa 5 minuti)
  1. Crea l'archivio dei dati. Su github.com tocca «+» in alto → «New repository». Nome: preventivi-ieci-dati. Scegli Private (importante). Spunta «Add a README file». Poi «Create repository».
  2. Crea il codice di accesso. Tocca la tua foto → Settings → in fondo «Developer settings» → Personal access tokens → Fine-grained tokens → «Generate new token».
  3. Nome: Preventivi IECI. Scadenza: la più lunga disponibile. «Repository access»: Only select repositories e scegli preventivi-ieci-dati.
  4. «Permissions» → «Repository permissions» → Contents → Read and write. Poi «Generate token» e copia il codice (inizia con github_pat_). Si vede una volta sola.
  5. Qui sotto scrivi iltuoutente/preventivi-ieci-dati, incolla il codice e premi «Collega e sincronizza».
  6. Sugli altri dispositivi ripeti solo il passo 5: stesso archivio, stesso codice (conservalo in un posto sicuro).

Alternativa avanzata: Google Drive

Archivio, listino, dati ditta e stile vengono salvati in una cartella riservata all'app nel tuo Drive e uniti su tutti i dispositivi. L'app non vede gli altri tuoi file.

Come ottenere il Client ID (una volta sola)
  1. Apri console.cloud.google.com e crea un progetto (es. «Preventivi IECI»).
  2. API e servizi → Libreria: abilita «Google Drive API».
  3. API e servizi → Schermata consenso OAuth: tipo «Esterno», nome app e tua email; poi «Pubblica app» (così l'accesso non scade).
  4. Credenziali → Crea credenziali → ID client OAuth → Applicazione web. In «Origini JavaScript autorizzate» inserisci l'indirizzo mostrato qui sotto.
  5. Copia l'ID client (finisce con .apps.googleusercontent.com) e incollalo qui.

Pubblica una versione nuova su GitHub

Niente più «Upload files»: scegli lo zip IECI-preventivi-Android-PWA.zip, il programma lo apre, lo carica sul tuo GitHub in un solo passaggio e tutti i dispositivi si aggiornano da soli. Funziona anche dal telefono. È gratis.

Come creo il token (1 minuto, gratis)
  1. Su github.com apri: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nome a piacere, scadenza «No expiration» (o la più lunga), Repository access → Only select repositories e scegli il repository dell'app.
  3. In «Repository permissions» imposta Contents: Read and write. Nient'altro.
  4. Premi Generate token, copia il codice che inizia con github_pat_ e incollalo qui sopra.
